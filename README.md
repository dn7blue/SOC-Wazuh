# SOC-Wazuh

### He realizado un proyecto en mi HomeLab elaborado con wazuh y tres maquinas virtuales para simular un entorno realista.

### Arquitectura del Laboratorio:

Ubuntu Server: Wazuh Manager (SIEM centralizado).

Ubuntu Desktop: Endpoint monitorizado (Agente Wazuh y cortafuegos UFW).

Kali Linux: Máquina atacante para emulación de amenazas.

### Objetivos del Proyecto: Monitorización de endpoints, análisis de logs de autenticación y creación de reglas de detección personalizadas.
